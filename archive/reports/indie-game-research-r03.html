本轮新增判断

独立购买价值并不要求每一个基础动作从未出现过。成熟动作可以通过新的决策、反馈和进展组织成为完整产品。是否获得购买、是否让目标玩家满意、是否值得长期维护，仍然要分别证明。

《BALL x PIT》的发行商披露增强了“简单动作经过完整融合仍可获得规模购买”的证据；《Jusant》未达公司预期则说明，作品受到认可与达到商业目标可以分离。两个事实都不能单独说明我们应该选择什么类型。

三组具体比较

PEAK / Cairn / Surmount / Jusant

同样是攀爬，玩家购买的是不同经历

已核对的机制与背景：PEAK 把援助、绳索、耐力受损与每日地图连在一起；Cairn 强调落点、姿态、路线和生存物资；Surmount 有物理攀爬与本地双人；Jusant 组织工具、耐力和探索中的安静旅程。

规则关系示意：同样面对一段难爬的岩壁，在 PEAK 中，你可能已经抵达平台，却需要帮助落后的朋友；在 Cairn 中，注意力更集中于下一处手脚支点与身体平衡；在 Surmount 中，与同伴相连的物理运动成为操作对象；Jusant 的工具使用又与继续探索环境相连。这不是实机记录。

对应玩家回报：胜任感可以表现为救场、精确控制、掌握物理运动或找到道路；关系需求和情绪节奏也不同。一个动作词并不能确定玩家买什么。

真正需要做的决定：合作的价值要通过相互影响的具体行动说明。队友不仅一起出现在地图上，还必须能让局面变好、变糟或值得记住。单人作品则可以把同样的身体动作发展成更集中的掌握过程。

同需求竞品关系：购买场景比“爬山”标签更有区分力：朋友找共同冒险、个人想挑战动作与资源、两人本地玩物理互动、个人想体验氛围与探索。视角、联网方式、失败成本和叙事分量均影响替代关系。

反例与证据边界：PEAK 的销量披露与 Jusant 未达公司预期不能组成严格的因果对照：制作成本、定价、平台、宣发与发行时点都不同。Surmount 缺直接财务证据，不能把它当作已知商业失败。

对候选的影响：保留共享物理问题这一研究方向，但放弃用“又一款合作攀爬/载具游戏”作为机会论证。需要指出新的共同难题，以及熟练者、新手各自能贡献什么。

BALL x PIT / Peglin / Rack and Slay

BALL x PIT：简单动作可以承载多个尺度的进展

已核对的机制与背景：BALL x PIT 把弹球碰撞、局内融合与基地建设连接起来，基地提供后续能力和角色。发行商披露首发十周Steam销量超过100万份，证明这种完整产品获得了规模购买，未证明某一子系统单独导致销量。

设计关系示意：战斗中先处理正在推进的威胁；得到新球后，决定围绕当前能力继续强化还是改变组合；回到基地，投入所得以打开下一种角色或玩法。这三个尺度分别改变当下行动、本局组合和下次出发条件。

对应玩家回报：分析假说：熟悉动作让玩家快速预期结果，连续碰撞提供即时反馈，融合与新角色让“再来一次”有不同内容可期待。局外进度可能使失败也留下成果，但这要与操作胜任的承诺相匹配。

真正需要做的决定：应先确定玩家主要想获得增长与组合的爽感，还是凭操作挽救弱构筑的挑战。它们可以重叠，却不能假定属性成长对所有玩家都是同一份奖励。

同需求竞品关系：Peglin 将发射连接回合战斗；Rack and Slay 让碰撞把敌人送进洞或陷阱；BALL x PIT 另有基地与角色进展。研究对象应是发射前判断、发射后可控性和失败后的改变，而不只是都在“弹球+肉鸽”。

反例与证据边界：预设抽样中的正评看重角色差异与较轻松的循环，负评有人更期待操作能弥补数值不足。双方甚至对同一角色变化有不同评价。样本反映预期分歧，不证明当前平衡失当或哪方占多数。

对候选的影响：候选 E 保留，但要把购买承诺写清：靠角度与场地规划取得优势，还是不断长大并发现强组合。新增系统应服务这一承诺，不能只增加重开的手续。

Blue Prince / Outer Wilds / Alchemists

Blue Prince：随机过程可以促成发现，也可能增加验证想法的成本

已核对的机制与背景：Blue Prince 让玩家选择门后的房间，每日重置布局，部分进展保留。开发者访谈说明房间草图与第一人称谜题如何结合。变化的访问过程不能自动等同于不断生成新谜底。

规则关系示意：面对一扇门，你选择能补充资源的房间，或有助于继续探索的房间。前期几乎每一种选择都可能提供新线索；后期已锁定一个待验证想法时，你可能只需要特定条件，这时其他变化是否仍有价值就成了问题。

对应玩家回报：分析假说：尚有多个未知目标时，随机提供的方向可以促成意外发现；目标收窄后，同一随机结构可能变成等待。玩家掌握相关规律、保有多个可推进的目标时，又可能把它重新理解为适应性规划。

真正需要做的决定：有必要分别衡量“想出一个值得验证的解释”与“获得验证它的机会”。困难可以发生在推理本身，也可以发生在取得条件，玩家未必同样喜欢二者。

同需求竞品关系：R02 中 Alchemists 改变隐藏属性答案，让既有规律仍能用于推断；Blue Prince 公开描述主要强调路径与房间选择围绕谜题变化。Outer Wilds 则作为知识探索的对照。它们随机或重置的部分并不相同。

反例与证据边界：六条预设样本中，正评和负评均有人提到后段摩擦，也有正评把房间出现规律本身看作值得学习的谜题。不能从抱怨直接推出“删除所有随机”是改进；那可能同时移除核心体验。

对候选的影响：候选 D 增加一项具体筛选：玩家已知道自己想试什么时，阻挡他的究竟是一个新决策，还是重复取得既有条件。这个问题比“无限生成谜题”更值得先研究。

两个需要继续验证的解释：
① 同一个系统的作用可能随玩家知识增长而改变：未知很多时适合探索，目标明确时更在意验证的可达性。
② 同一个成长系统可能服务不同期待：有人喜欢越来越强和新角色，有人希望低属性也能靠操作挽救局面。

上述解释属于研究假说。评价来自2025年，记录时长是本轮页面显示值，可能包含挂机，也不是发表时的时长。没有把玩家声称的具体数值、等待时长或缺失功能当作2026版本的实机事实。

对设计的意义在于定位受众和取舍，而非看到一个抱怨就增加一项功能。例如让已知地点随时可达，可能降低重复，也可能破坏依赖资源与路径安排的体验；需要先判断哪种困难是产品承诺的一部分。

以成品为终点，原型和维护都要算清楚

案例开发者材料支持的事实对AI主导制作的有限启发
PEAK官方背景记载2025年2月共同Game Jam，6月发行，并列出多位已有开发经验的参与者。不能把一次Game Jam的日历长度等同于完整成本，也不能据此承诺AI同样时长交付。
Blue Prince开发者表示核心很早确立，但后来经历多年开发与大量试玩观察。“第一周有好原型”与“可出售的完整体验”之间可能还有很长的内容和验证工作。
Cairn开发者在2025年10月说明内容已完成，仍需为优化、除错和打磨推迟发行。功能清单完成之后仍有交付负担；AI能实现机制不等于已经完成手感与稳定性。
PEAK 的当前维护方式本轮官方FAQ表示大型内容更新已结束，将继续修复维护；同时说明离线单人可用。长期可以买到并游玩，不一定要求不断扩充功能。该例不代表所有合作游戏都适合同样方式。

AI主导开发的候选仍需检查几类独立工作：核心操作与反馈，内容和规则的组织，组合状态验证，体验与平衡观察，最终稳定性，以及发行后的维护。当前没有测量这些步骤能被AI缩短多少，不给出虚假的开发周期或成本承诺。

近期作品还提醒我们，叙事、美术与玩法不是三个互斥选项。即使主要竞争力是玩法，空间可读性、动作反馈、声音与一致的表现仍然参与兑现玩家体验。它们需要服务玩法，而不能在研究时直接视为可忽略的附属品。

判断更新与下一步

研究项本轮推进仍未解决
购买价值新增官方销量与未达预期披露，市场层面证据比评论数量更强。仍缺代表性样本和多数产品成本，暂不能计算新品成功率。
候选 C / 合作攀爬比较把共同冒险、精确单人掌握、本地物理互动分开。需要新的共同难题，题材加联网仍不足以支撑独立购买理由。
候选 D / 推理区分随机答案、随机访问路径与玩家已经掌握的知识。重点检查后段验证一个假说的机会成本；不先承诺无限谜题。
候选 E / 简单动作BALL x PIT 增强了成熟动作经完整融合仍可规模销售的证据。不因此提升我们具体候选的成功概率；先确定主要依靠技巧还是成长满足。
长期性官方产品可以明确结束大型更新，同时保持可玩与维护。长期销售、无限内容、同一用户长留继续分别评估。
AI主导制作本轮实例显示原型、内容、验证与收尾可能是不同的时间段。不把现成游戏的人力周期直接换算成AI开发预算，也不把体验验证省略。

下一轮工作

  1. 将目前的机制研究收敛成可竞争的产品假说，但继续保留不同受众路线；每个候选至少写一个清楚的购买承诺、典型局面和玩家拒绝购买的理由。
  2. 对 D、E 做更细的文字对照，检查真正反复发生的决定是否与最接近竞品不同；可以融合，但不能靠增加题材与物品数量解释差异。
  3. 新增一条围绕社交陪伴或创作表达的具体假说，与工程/推理路线对照，避免研究再次偏向高思考负荷。
