目前能作出的取舍

优先研究少量动作或工具不断出现新用途，并行研究有限旅程中的连续发现。小型工程保留窄问题；合作须有实际的共同工作与恢复方式；大型持久世界后置。异步构筑和公开信息对抗仍是比较对象，尚无足够不同的自有产品表达。

这里的“优先”指值得继续找证据，没有市场成功率排名的含义。两条方向都已有优秀竞品。需要回答的是：一位已经玩过近邻作品的人，为什么还愿意买这款，反复做其中哪项工作？

第一性分析采用可检验的解释：玩家做了什么、看见什么变化、为什么愿意再做一次。掌握动作、理解规律、兑现计划、改善环境、表达自己、与朋友完成任务，都可能是主要回报。它们不应全部被筛成复杂策略。

归档只针对当前表达。有固定解、可以安全慢行、已有近邻，都不自动等于不好玩；但如果购买承诺是多种用途或持续协作，就需要相应局面支撑。合并标签、扩大组合数量和加入随机奖励都不能代替它。

研究方法也需要收敛。已有比较名单足够广，继续无差别扩充资料的收益降低。后续应让一个完整表达接受具体反例，而不是通过更多功能延长它的寿命。

已有游戏为什么好玩：落到玩家的行动

这里的第一性分析是可被反例修正的解释，不是成功公式。“自由”“合作”“收集”“构筑”都是描述，必须进一步说明玩家实际做什么、获得什么。

参照具体局面主要回报要防止的误读
Slay the Spire 研究这张牌现在能解围，却可能让后面抽不到关键牌；路线、生命、牌组共同决定眼前该不该拿。期待、适应与逐渐掌握：不是简单的随机奖励，而是在当前条件下理解价值。如果大多数奖励只让数字增大，没有改变打法，重开只是重复凑数。
Factorio / Necesse 研究先亲手做一项工作，再让机器或居民代劳；腾出的注意力拿来组织更大的生产与远征。让自己的安排持续起作用，同时面对新的组织问题。自动化如果只剩资源增长，没有新的目标；或者维护工作吞掉冒险，都会改变产品承诺。
Terraria / Core Keeper 研究探索拿到能力，能力打开新地点；开出的路、布置的场地、建好的后方又被战斗和下一次出发使用。成长、发现、空间归属与多种任务互相帮助。打Boss的人不一定愿意转向装修；有大量材料和地图，不等于有下一次主动计划。
Teardown / Shipbreaker / Besiege 研究同样是破坏：可以为逃跑修路、按结构安全拆船，或验证自己造的机器是否能完成任务。分别是计划兑现、熟练作业、创造方案。大场面只是其中一部分。把“爆炸很爽”当作它们共有的完整乐趣，会选错玩家实际愿意做的工作。
PlateUp! / Overcooked! 2 研究当下要把菜送出去；前者还让经营选择和布局持续改变后续厨房的压力。默契、应急补位，以及我之前的安排真的帮助了大家。有人喜欢紧张重开，有人希望直接重练难点；喊话更多、每人一直忙，并不是统一的成功标准。
Baba Is You / Patrick’s Parabox 研究先理解一种关系，再在另一个局面发现它的不同用途；进展发生在玩家脑中。从误解到领悟，以及用已学知识看懂新情境。如果后续只把答案藏深、推演变长，没有新的理解，难度增加未必兑现发现承诺。
PowerWash Simulator / Tiny Glade 研究看见环境稳定改善，或用简单输入做出自己满意的形状，继续修到“就是我要的样子”。完成感、控制感与表达；可以不依赖失败、竞速或复杂资源竞争。创作工具若猜错玩家意图，清洁若卡在难找的最后一点，简单操作也会变成摩擦。
Luck be a Landlord / Ballionaire / BALL x PIT 研究前两者让配置后迅速看到连锁结果；后者保留实时行动，让玩家亲手应对与兑现。前者更强调试配和理解，后者还要求动作参与；两种节奏都有自己的受众。“同样加入构筑”不能推出同一种购买理由；给试配玩家增加动作要求可能反而伤害核心。

融合要同时计算收益和负担。餐厅布局改变端菜路线，两个系统就发生了联系；但额外经营也可能成为动作玩家不想做的家务。受众不会因为合并两个标签而直接相加。节奏动作融合中的输入与注意力取舍

连续价值可以来自更熟练，也可以来自新理解。不能要求每次重复都必须出现新策略，更不能把组合数量、隐藏规则数量或随机内容数量当成耐玩证据。

目前怎样分配研究优先级

方向具体想得到的体验现在的边界
优先：少量动作的新用途同一个物体移动后既改变原处的通路，又能在新处起作用；后续任务真的调用这个结果。需要同时检查亲手操作是否舒服、不同局面是否值得做。不能靠加词条救活单调动作。
并行：有限旅程的连续发现新证据改变旧解释；学会一种关系后，在新场景看懂原先不懂的东西。可通关、可结束。难点是线索、公平性、提示和节奏，不能靠大量AI文本补足。
窄研究：小型工程与工具改用手中的绞盘可以牵引，也可以拆到高处吊货；自己的安排兑现为结果。已有MFL、RoadCraft、Besiege等强近邻。原设想B暂停扩分支，先解决独立购买理由。
有条件：围绕共同物体的合作我的操作让朋友马上能做下一步，配合成功被两个人感受到。等待和轮流未必是缺点，但要符合受众；人数、水平差、恢复和网络都影响核心。
后置：大型持久世界修好的路、基地和生产体系成为下一次出发的条件，朋友也能使用。保留需求，暂不承诺全套生存建造与多年内容。原作积累后的体量不是首作规格。

这是现阶段的研究排序，不是市场成功率排名。没有完整发行分母、同规格成本或目标玩家数据支撑概率计算。

证词的视角

根据两位证人各自的位置与画面，把人和物的相对关系摆回现场，判断“看上去重叠”是否意味着“当时正在接触”。新证据应改变原有解释。

借风进站

控制风筝的角度和绳长，让被它牵引的小车越坡、钻过低桥并停进站台。小车进入背风区时，风筝可能仍在上层有风处；卸货后重量变化，再次停车需要不同准备。

保留原因：受风部件与车体可以位于不同区域，绳长可能真正改变牵引来源。其核心回报是亲手把一段连续控制做顺，允许熟练后的重复本身有价值。

巡回工坊

商业证据与2026—2028年的判断

历史披露可用于判断的事情不能外推的事情
Backpack Battles：发行方2025年5月23日公告全球销量100万份。松竹公告库存摆放与构筑组合曾获得大规模付费需求；融合可以成立。不是2026年最新累计，不是净利润，也不是同类游戏成功率。一次成功没有提供发行分母。
Railbound：2023年PARP报告称Steam售出5万份，所述回本线约3万份。报告第46页有限、完整、可通关的付费作品，有具体覆盖成本的案例。是历史访谈式披露，未给完整成本拆分或审计利润；不能套成本到AI项目。
Pawnbarian：作者在发售约2.5个月后的复盘中自报退款后付费销量8400余份、分成与税后约3万美元净所得，对应约20个月工作。作者复盘销量、扣除项和劳动周期必须一起看；规则与画面规模小也不能直接推断便宜。自报历史数据，约3万美元并非另行扣除作者20个月劳动价值后的会计利润；不是今日累计或AI生产率预测。

最重要的取舍是把长销与高时长拆开。同一玩家不断重开、朋友长期共同游玩、新玩家多年后持续买入、开发者不断更新，是不同路径。有限体验也可以争取持续销售；现有案例只证明这条商业路径存在，没有验证我们的草案或保证多年长尾。

《泰拉瑞亚》提供的启发，是探索、能力、空间和后方建设能互相帮助；它多年积累后的体量不应直接变成首作规格。我们需要首先交付一段完整且有辨识度的体验。

对未来两年的工作判断：以下属于案例推断，不是品类增速预测。

  • 更优先找可直接展示的因果变化。玩家看见一次动作怎样解决问题、怎样改变后续，购买理由更容易具体表达。实际商店转化仍需测量，不能用“视频很有传播感”自证。
  • 考虑完整、边界明确的体验。首发即可兑现承诺，有机会减少依赖后续内容补全的负担；这不等于短游戏自动更好卖。
  • 合作必须出售双方能感知的贡献。在线只是方式。水平差、等待、失败恢复、朋友是否有空，会影响实际使用机会。没有证据默认四人联机优于单人或双人。
  • 若AI继续降低代码与素材产出门槛，筛选与打磨更值得投入。可信规则、可读反馈、内容节奏、美术和声音的一致性仍决定实际体验；当前没有量化AI项目的成本优势。

玩法优先允许剧情、美术与声音帮助玩法兑现回报。世界观换皮和更多功能不自动提供独立购买理由；完全前所未见也不是唯一道路。融合需要改变玩家持续做的工作，并由完整体验支撑。

以终为始：购买承诺怎样反推内容

可能的承诺开头必须让人感到中段必须继续发生完成后为什么满意
“我能用手头的东西想出办法”一件工具的作用看得懂，亲手执行有反馈。同一工具出现不同用途，场地改变选择。自己解决过一组值得记住的问题；可进一步追求更顺的方案。
“我逐渐看懂一个陌生世界”猜测可以通过观察被修正，而非只能猜作者心思。旧知识迁移、新证据改变旧解释。获得完整理解和结束感，愿意向下一位玩家推荐。
“我们练成了一段配合”我的行动能被朋友看见，并帮助他完成下一步。贡献、节奏与恢复方式有变化。留下共同经历，愿意再练、再挑战或带朋友玩。

这些仍是产品假说。没有一行已被证明可卖，也没有一行要求所有玩家无限重玩。后续需分别审视购买动机、完整体验与生产可行性。

接下来的研究怎样更接近决策

本次先完成整理。后续保持跨方向，但每次围绕能改变去留的问题推进，不再以增加轮数、类型或功能数量作为目标。

  1. 明确主要买家和购买句。他想获得掌握、发现、表达还是共同完成？哪些负担愿意接受，哪些会让他离开？
  2. 把完整流程写出来。开场让人尝到回报，中段至少给出具体变化，结尾兑现承诺。重复练熟也可以是价值，不能只认可新策略。
  3. 对照最近竞品和合法省事方法。指出差别发生在哪个决定、操作或反馈；接受绕路、直接设规则、先清场与安全慢行，查看产品在这些条件下还剩什么价值。
  4. 决定去留。若只能靠加素材、配方、随机词条或限制维持说法，就停止当前版本扩写；保留有价值的玩家需求。

在“不立项、不实现”的边界内，可以继续做规则、完整流程、竞品、纸面反例与历史商业资料核对。动作手感、目标玩家意愿、付费转化和AI实际交付工期，不能由这些工作替代。后续若要判断这些问题，需要相应的新证据；本报告不默许进入实现。

现有材料支持继续收窄研究，并不支持现在选一个草案开做。两条主线有明确理由保留，五份近期表达有明确缺口，八个正式跟踪设想没有升级。下一阶段应提高完整新玩法的产出质量。
