# 普通难度设计与验证入口

版本：2026-10-23 / v0.2。范围：从零设计的 Steam 付费地下城挂机游戏。引擎 Unity 6，原型使用本机已安装的 **6000.6.5f1**。

用户确认的普通流程为六区、每区九关，每关三场遭遇；第5关精英、第9关Boss，普通首通目标55—65小时，预算56小时。目标与实测严格分开。

## 数据与证据

- [关卡与怪物数据](../../data/normal-campaign.json)：54关、162场遭遇、区域前置与怪物引用的权威数据。
- [角色配置](../../data/characters.json)：角色身份、招募资格、主动技能意图；战斗系数是原型起点。
- [数值模型](../../data/balance-model.json)：成长锚点、解锁、数值上限与分析假设。
- [市场模板](../../data/market-items.json)：24个设计模板；`steam_itemdefid: null` 表示尚未部署。
- [检查工具](../../tools/check_design.py)：静态一致性与可复算分析，不能证明趣味或56小时首通。
- [Unity原型说明](../../prototypes/NormalCampaign/README.md)：占位交互、构建和运行方法。
- [本次验证记录](../../production/qa/normal-campaign-validation.md)：只记录实际执行与未运行的检查。

文档中的「确认规则」来自本次用户实施请求；「原型参数」可在测试后调整；「待验证目标」不是已完成的体验承诺。其他难度未配置，真实市场后端未接通，正式美术未生产。

原仓库的 `docs/` 与 `archive/` 是2026-10-12结束的历史探索，不作为新游戏的玩法约束；原始归档及其清单不修改。
